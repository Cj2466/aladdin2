1. THE MATHEMATICS, STATED ONCE
============================================================================
Over UNIQUE-TERM sets, J(A,B) = |A n B| / |A u B|, and since
|A n B| <= min(|A|,|B|) while |A u B| >= max(|A|,|B|),

    J(A,B)  <=  min(|A|,|B|) / max(|A|,|B|)   ==   c, the VOCABULARY-SIZE
                                                   CEILING

with equality exactly when one filing's vocabulary contains the other's.
Two consequences the original check missed:

 * c IS NOT RAW DOCUMENT LENGTH, which is what the original check measured.
   A filing can double in word count while adding no new distinct word (c
   unchanged), or shrink overall while adding a handful of new terms (c
   falls). The two variables are only loosely related, and the 180-pair
   independent sample measured that: corr(jaccard, length ratio) = -0.566
   while corr(jaccard, c) = +0.724.
 * J IS AN EXACT FUNCTION OF c AND ONE OTHER QUANTITY. With m = min(|A|,|B|),
   M = max(|A|,|B|), i = |A n B|: from J = i/(|A|+|B|-i) and c = m/M,

       o  ==  i / m  =  J (1 + 1/c) / (1 + J)

   o is the CONTAINMENT RATIO: the share of the SMALLER filing's vocabulary
   that survives into the larger one. It is 1.0 whenever one vocabulary
   contains the other no matter how different their sizes, and falls only
   when terms were genuinely DROPPED. (c, o) is a complete, invertible
   reparameterization of Jaccard — so the confound question has an exact
   answer rather than a regression-shaped one: replay c alone, replay o
   alone, and see which carries the Sharpe. Verified numerically, not
   trusted: rebuilding J from (c, o) across all 1,617,605 real panel cells
   reproduces it to a largest absolute error of 4.44e-16.

6. THE SAME TEST ON THE PROPOSED FALLBACK — WHICH ARGUES AGAINST DEMOTING
============================================================================
lazy_cosine_rf_h126_ivol (reproduced +0.5001 / DSR 0.6377) is the spec a
demotion would move to, on the argument that cosine reads raw term-COUNT
vectors, is invariant to each vector's magnitude, and therefore has no
min/max unique-vocabulary bound of the Jaccard kind. As mathematics that is
correct. As an empirical claim about confound exposure it does not survive
measurement:

  Spearman(cosine/risk_factors, risk_factors vocabulary ceiling) = +0.539
  Spearman(jaccard/full,        full vocabulary ceiling)         = +0.425
  Pearson (cosine/rf, rf ceiling) = +0.445 (R^2 0.198), vs jaccard's +0.699
  Risk-factors-ceiling-only replay, h126/ivol: Sharpe +0.0334, DSR 0.1083

So the candidate replacement has a WEAKER linear relationship to its scope's
ceiling and a STRONGER RANK relationship — and rank is what a quintile sort
consumes. Its own ceiling carries no returns at all (+0.0334), which is
reassuring for it, but the same is broadly true of the incumbent's ceiling
(+0.1875 against a 0.95 bar). Demoting on the evidence in this document would
swap a measured exposure for a larger unmeasured one, and would additionally
move the registration onto a scope with 90.0% section coverage that is
differentially composed by which filers' headings parse (the incumbent's
"full" scope has 100.0%). That is why the recommendation is to keep.
