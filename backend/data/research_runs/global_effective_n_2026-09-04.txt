HOW THIS NUMBER IS USED, and the one guard on it
------------------------------------------------------------------------------
  effective_n_clustering.py's own docstring states that E[K] is bounded to
  [2, N-1] by construction and that k-means UNDER-counts genuinely
  independent trials, which LOWERS the expected-max-Sharpe hurdle --
  anti-conservative. That is why the module shipped unwired. The wiring in
  global_effective_n.dsr_n_trials therefore takes max(local grid size,
  global effective N), never the global number alone: the denominator can
  only ever GROW relative to the status quo, so no family's DSR can be made
  more lenient by this change, and the [2, N-1] under-counting bound can
  only cost conservatism this project did not already have.
