POINT-IN-TIME — THE HEADLINE CORRECTNESS NUMBERS

WHAT THE GRID'S STRUCTURE ACTUALLY SAYS
--------------------------------------------------------------------------------

 * THE SIGN IS RIGHT, THE SIZE IS NOT. 35 of 36 specs are positive, in the
   paper's documented direction. But the 36 specs are correlated variants of
   ONE idea, so that sign count carries roughly the information of a single
   positive draw — which is precisely what sigma_sr = 0.161 already prices in.
   The DSR, not the sign count, is the number to read.

 * COUNT BEATS SHARE ALMOST EVERYWHERE, AND THAT IS THE UNCOMFORTABLE NUMBER.
   Mean Sharpe +0.398 for `count` against +0.184 for `share`, with `count`
   winning 17 of 18 matched pairs. `share` is the popularity-controlled
   variant, pre-declared precisely to detect the failure mode where "many
   managers call this their best idea" is really "many managers hold this,
   because it is big". That count > share so systematically is direct
   evidence that a MEANINGFUL PART of the raw signal is a popularity/size
   effect rather than conviction.

 * BUT IT IS NOT PURELY A SIZE ARTIFACT, and the honest reading has to say
   both halves. The single best spec in the whole grid IS a `share` spec
   (+0.573, DSR 0.778), beating the best `count` spec (+0.543, DSR 0.748),
   and its own matched `count` counterpart (+0.499). So popularity explains
   much of the average but not the maximum. Neither reading is strong enough
   to matter at a DSR of 0.778 against a 0.95 bar; both are recorded because
   the pre-registration committed to reporting this comparison either way.

 * THE LONGEST HOLD IS THE BEST ONE, which is the one result that sits
   comfortably with the source. h252 gives the best mean (+0.388) against
   h63 (+0.262) and h126 (+0.222). The paper's Figure 4 claims best-idea
   outperformance "does not revert in the months or even years after first
   appearing in the portfolio", and a signal whose best expression is its
   longest hold is at least consistent with that, rather than with a
   short-lived announcement effect. Contrast the sibling asset-growth family,
   where the literature's own rebalance frequency was the WORST hold.

 * PORTFOLIO_TILT IS THE BEST MEASURE (mean +0.364) ahead of conviction
   (+0.273) and market_tilt (+0.235). Read cautiously: portfolio_tilt is the
   measure that leans hardest on the disclosed aggregate-13F capitalisation
   proxy (module section 2), so its edge over conviction — the one EXACT,
   proxy-free measure — is as easily a property of the proxy as of the
   economics.

 * THIRTEEN OF THIRTY-SIX SPECS EXCEED THE >= 0.5 DSR SCREENING FLOOR this
   project has previously used to select forward-validation candidates, while
   NONE come close to this family's own pre-registered 0.95 bar. Reporting
   only the maximum would understate how much of the grid sits above that
   floor. It does not change the verdict — 0.5 is a screening floor, not a
   significance bar. NOTHING FROM THIS FAMILY IS REGISTERED FOR FORWARD
   VALIDATION; that is a separate, later, human decision and this run makes
   no recommendation either way.

A DATA-HYGIENE DECISION MADE AFTER PRE-REGISTRATION, DISCLOSED NOT BURIED
--------------------------------------------------------------------------------
MAX_REPORTING_LAG_DAYS = 365 is NOT in the pre-registration. It was added
during the build, from INGESTION DIAGNOSTICS ONLY and before any backtest

delinquent filers reporting books up to 3,027 days old. Keying visibility on

7,733 filings. No result influenced the choice of 365.

AN INCIDENTAL FINDING WORTH MORE THAN THE BACKTEST: THE 2023 UNITS BREAK
--------------------------------------------------------------------------------
The per-filing VALUE unit classifier (provider section 2) independently
detected a REGIME CHANGE in how 13F filers report the VALUE column, from the
data alone, with no hardcoded date:

    2021q1..2022q4        1.2% - 1.6% of filings in whole dollars
    2023q1               79.9%
    2023q2..2023q4       86.3% -> 89.4%
    2024 .. 2026q2       90.5% -> 96.0%

VERIFIED against the primary source: the CURRENT Form 13F instructions
(https://www.sec.gov/files/form13f.pdf, fetched this build), instruction 8,
state verbatim "Enter values rounded to the nearest dollar", and the
information-table header reads "(to the nearest dollar)".

LABELLED AS INFERENCE, NOT FACT: the break at 2023q1 is consistent with the
form's units convention changing for 2023 reporting, with a multi-year tail
of filers still on the old thousands convention. NO explicit effective-date
statement was located in the fetched instructions, so the CAUSAL attribution
is an inference. The MEASUREMENT above is not — it is counted from the real
archives.

WHY IT MATTERS BEYOND THIS FAMILY: any 13F pipeline that hardcodes "VALUE is
in thousands" — the convention every pre-2023 description of this dataset
states — is wrong by a factor of 1,000 for 80-96% of filings from 2023
onward. Portfolio WEIGHTS survive that error (same-unit ratios), which is
why conviction is exact here regardless; anything comparing value ACROSS
filers does not. This family's aggregate market-weight vector and its $5m
screen both do compare across filers, and both would have been corrupted
over the entire recent half of the sample.

C2  THE "BOUNDED WINDOW" ON IDENTIFIER RESOLUTION WAS NEVER IMPLEMENTED
--------------------------------------------------------------------------------
Pre-registration section 4 (SOURCE B) says a (cusip, ticker) pair "is only
applied to 13F filings in a bounded window around the file that evidences
it", and the provider's own section 3 said the same. There is no window.
CusipTickerMap.resolve takes the observation NEAREST IN TIME in EITHER
direction at ANY distance, so a filing can be named using a file published
after it. The pre-registration is not edited; the code comments have been
corrected to describe what the code does.

MAGNITUDE, MEASURED over every mapped CUSIP at four sample dates: under the
shipped map, 10 of 3,198 resolvable probes (0.31%) would differ under a
strict latest-at-or-before rule; under the fixed map, 2 of 3,236 (0.06%). The
resolution rule was deliberately NOT changed, for two reasons: choosing a
window width after seeing results is exactly the post-hoc freedom this
family's pre-registration exists to remove, and the coverage cost of a strict
rule is far larger than the impurity it removes - 372 probes have no
at-or-before observation at all and would simply drop out, roughly 190x the
number affected by the leak. Disclosed and measured rather than silently
re-specified.

C3  ONE HALF OF THE POINT-IN-TIME CONTRACT WAS UNTESTED
--------------------------------------------------------------------------------
Section 3 and the report above both claim BOTH cross-manager statistics are
bounded to prior-period filings public strictly before the current period
ended. Both ARE, in the code. But mutation testing over the point-in-time
gating, CUSIP resolution, count/share normalisation, DSR wiring and units
classifier - 24 mutations - found exactly one survivor: deleting the bound on
the aggregate MARKET-WEIGHT vector left the entire suite green. The activeness
cutoff's identical bound had been pinned when that leak was fixed in f3ab150;
the market-weight one never was, so the same defect could have reappeared on
the other half of the contract with nothing to catch it. It is now pinned by
a three-period differential test, and 24 of 24 mutations are killed.

C4  "DIRECT EVIDENCE" OVERSTATES WHAT COUNT-VS-SHARE SHOWS
--------------------------------------------------------------------------------
The report says count beating share is "direct evidence that a MEANINGFUL
PART of the raw signal is a popularity/size effect". That inference treats
`share` as a clean popularity control. It is not one, and the asymmetry is
large. Measured as the cross-sectional rank correlation between each panel's
signal and the number of eligible managers holding the name, over 200 sampled
trading days on the real panel:

                       rho(count, holders)   rho(share, holders)
    conviction               +0.362                -0.723
    market_tilt              +0.356                -0.753
    portfolio_tilt           +0.240                -0.853

`count` does carry the popularity tilt the pre-registration predicted. But
`share` does not remove it - it replaces it with a much STRONGER tilt of the
opposite sign, roughly 2.5x the magnitude. `share` is close to a
thinly-held-name bet. So the count-minus-share gap conflates removing count's
popularity tilt with imposing share's own reverse tilt, and it cannot cleanly
size the popularity component. The honest statement is that the comparison is
SUGGESTIVE of a popularity component in `count`, not direct evidence of its
size. By the same token the "BUT NOT PURELY A SIZE ARTIFACT" reading is also
weaker than stated: the best spec being a `share` spec does not show the
signal is not size-driven, only that it leans on the opposite size tilt.
Neither reading changes anything at DSR 0.777 against a 0.95 bar.

C5  A MINOR ONE, RECORDED NOT FIXED
--------------------------------------------------------------------------------
The panel keys a manager's current view on CIK alone, so the latest-FILED
record wins even when it describes an OLDER quarter than the view it
replaces. Measured: 491 of 73,554 supersessions (0.67%) regress to an earlier
report period. It is point-in-time honest either way (the later document
really is the newer public fact) and MAX_REPORTING_LAG_DAYS bounds the
staleness to a year, so it is recorded rather than changed.

WHAT IS UNCHANGED

the code, in the persisted rows, and in the re-run. Zero of 36 specs clear
the pre-registered 0.95 bar under either CUSIP map, and this family remains
an HONEST NEGATIVE.

E.2  THE HEADLINE CANDIDATE, AND THE THREE SPEC-LEVEL DEVIATIONS
------------------------------------------------------------------------------
  bi_portfolio_tilt_share_h252_quintile
     Sharpe +0.5734, PSR(0) 0.9725, DSR 0.7781 at n_trials=36, 2,890 days,
     12 formations, 87.2 names per leg, turnover 15.81, cost drag 0.0079.
     Naive pre-multiplicity t = Sharpe x sqrt(2890/252) = +1.94.

Measured against what the paper actually does, this one spec deviates on all
three of its own grid axes at once. Each quotation below is verbatim from the
retrieved PDF.

 (a) AGGREGATION. The paper, section V.B: "best idea in the portfolio is
     equal-weighted (if more than one manager considers a stock a best idea,
     we overweight accordingly)". That is `count`. The winning spec uses
     `share`, which module section 5 already states plainly is "THIS
     PROJECT'S OWN VARIANT ... it is NOT in the paper".

 (b) CADENCE. The paper, same passage (section V.B): "The portfolio is rebalanced on the
     first day of every quarter to reflect..." The winning spec is h252 -
     annual, four times slower. The paper's own cadence, h63, is in the grid.

 (c) MEASURE. portfolio_tilt is lambda[ft] - lambda[fVt], and lambda[fVt]
     needs a capitalisation basis. This project substitutes the aggregate-13F
     value vector, and module section 2 declares its bias IN ADVANCE:
     "securities with low institutional ownership (founder- or insider-
     controlled firms) carry understated weights in it, which mechanically
     inflates every manager's apparent tilt toward them. portfolio_tilt
     inherits the same proxy as its capitalisation basis." The paper's own
     measure for 13F data is `conviction` (section V.E, alpha[ft] = lambda[ft]),
     which needs no benchmark and no proxy at all.

E.3  THE SELF-FLAGGED PROXY CONCERN, INVESTIGATED: IT IS MEASURED, IT IS
     LARGE, AND IT IS WORST EXACTLY WHERE THE WINNING SPEC LIVES
------------------------------------------------------------------------------
The report above flags portfolio_tilt's edge as "as easily a property of the
proxy as of the economics". That decomposition had already been run - it is
correction C4 above - and its result was not carried into the summary reading.
Restated here because it is decisive. Rank correlation between each panel's
signal and the number of eligible managers holding the name, over 200 sampled
trading days on the real panel:

                       rho(count, holders)   rho(share, holders)
    conviction               +0.362                -0.723
    market_tilt              +0.356                -0.753
    portfolio_tilt           +0.240                -0.853   <- winning panel

THE WINNING SPEC SITS ON THE MOST CONFOUNDED CELL OF THE SIX. rho = -0.853
means its cross-sectional ranking is very nearly a monotone inverse of how
many institutions hold the name. A long/short on that signal is, to a first
approximation, LONG THINLY-HELD NAMES AND SHORT WIDELY-HELD ONES - an
institutional-ownership-breadth bet. Breadth of ownership is a studied
predictor in its own right (Chen, Hong & Stein, "Breadth of ownership and
stock returns", Journal of Financial Economics 66(2-3), 2002, pp. 171-205),
i.e. a DIFFERENT construct with its own published literature, not a neutral
nuisance. Note the direction is NOT settled in this family's favour either
way: CHS find that stocks whose breadth DECREASES subsequently underperform,
which if anything argues the winning spec's long-thinly-held leg should be
the losing side. Establishing which of the two constructs the +0.573 is
paying for would need the daily series and the panel, neither of which is
available (see E.6). Recorded as unresolved.

That is the si_dtc shape exactly: si_dtc was rejected at DSR 0.948 because its
long leg sat at the 72.7th percentile of trading VOLUME and only the 33.2nd
percentile of short interest - it sorted mostly on something other than the
paper's variable. -0.853 is a stronger version of the same finding, and it was
predicted in writing by this family's own module before the run.

C4 also cautions, correctly, that `share` "does not remove" count's popularity
tilt but "replaces it with a much STRONGER tilt of the opposite sign". Both
directions are confounds. The question for a registration is not which sign is
nicer; it is whether the ranked variable is the paper's. At -0.853 it is not.

WHAT COULD NOT BE DONE, stated rather than glossed: the -0.853 could not be
recomputed here from scratch. backend/data/form13f_raw/ is empty (0 files) and
gitignored, so the 53 SEC quarterly archives behind this panel are no longer on
disk. The figure is taken from this document's own committed, git-durable
verification section, produced by an independent agent; it is not re-derived.

E.5  THREE DEVIATIONS THAT NO SPEC IN THIS GRID CAN FIX
------------------------------------------------------------------------------

 (a) NEW FINDING - THE PAPER EXPLICITLY EXCLUDES THIS FAMILY'S QUESTION FROM
     ITS SCOPE. Section IV ("Data and Sample"), verbatim:

        "We identify best ideas as of the true holding date of the fund
         manager's portfolio as we are primarily interested in whether
         managers have stock-picking ability, not whether outsiders can
         piggyback on the information content in managers' holdings data."

     This family is the piggyback version, by construction and by design -
     every signal is keyed on FILING_DATE, which is the whole point of its
     point-in-time discipline. The support for that version is footnote 4:

        "Our work also documents that best-ideas trading strategies based
         only on holdings information as of the date the positions are made
         public also generate economically and statistically significant
         abnormal returns. See Figure 4 for direct evidence on this question."

     FOOTNOTE 4'S OWN CROSS-REFERENCE WAS CHECKED AND DOES NOT CONTAIN THE
     CLAIMED EVIDENCE. Figure 4 is captioned "Buy-and-hold abnormal returns
     of Best Ideas" and graphs "risk-adjusted cumulative buy-and-hold
     abnormal returns of the best ideas portfolio ... in event time"; the
     body text (section V.B) describes it as showing that "the superior
     performance of best ideas is not transitory" and "does not revert in
     the months or even years". That is a PERSISTENCE result. It makes the
     footnote's claim plausible by implication - a persistent effect should
     survive a 45-day disclosure lag - but it presents no public-date
     strategy, no alpha for one, and no t-statistic for one.

     So the entire literature basis for the hypothesis this family actually
     tests is ONE SENTENCE IN A FOOTNOTE of a paper that has been unpublished
     for seventeen years, whose own pointer to the evidence does not reach it.
     The report above and the module describe this correctly ("supported only
     by footnote assertion"); what is new here is that the footnote's
     cross-reference was followed and found not to close.

 (b) NEW FINDING - THE SHORT LEG IS NOT THE PAPER'S SHORT LEG, IN ANY SPEC.
     The paper's long/short portfolio is defined verbatim in the notes to
     Tables II and V as

        "the return on an equal-weight long-short portfolio that is long a
         dollar in each manager's best idea and short a dollar in each
         manager's investment-weight portfolio of the rest of their ideas,
         where the rest is defined as positions outside each manager's top
         ten ideas."

     That is a WITHIN-MANAGER spread: a manager's top conviction against that
     same manager's own low-conviction tail. This family's short leg is the
     bottom decile/quintile of the S&P 500 ranked by best-idea intensity
     ACROSS all managers - a different population answering a different
     question. The paper is explicit that its own non-best-idea population is
     flat, not negative: "The vast majority of the other stocks managers hold
     do not exhibit significant outperformance" (abstract). Its headline claim
     is a LONG-side alpha claim of 2.8-4.5% per year.

     Consequence: in all 36 specs roughly half the risk budget is spent on a
     leg the source paper makes no prediction about, carried at
     financing_bps_per_year = 0.0 (this project's standing, disclosed
     short-borrow optimism, which the report above already flags as
     flattering the short leg). This is not a deviation that spec selection
     can repair - the whole grid is long_short.

 (c) THE MANAGER POPULATION IS NOT RECONSTRUCTIBLE. Section V.E, verbatim:
     "To identify hedge funds and their holdings, we use the identification
     approach of Agrawal, Jiang, Tang, and Yang (2012) who manually classify
     all 13-filing institutions ... we study only relatively 'pure-play'
     hedge funds and thus exclude banks and mutual fund companies. Our final
     sample consists of 1,662 unique hedge funds." This family has 6,763
     distinct filers behind a name screen and an activeness cut. Module
     section 4 states the consequence for a negative result - "this manager
     universe is dirtier than the paper's, so a negative here is confounded
     with universe quality and cannot be read as a clean refutation". The
     symmetric statement is the one that matters for a REGISTRATION, and it
     is not in the module: a POSITIVE here is confounded the same way, and
     could not be attributed to the paper's mechanism either.

E.6  PRESERVATION SCORE - NOT COMPUTED, AND WHY. Stated plainly rather than
     skipped, because a silent omission is the failure mode this check exists
     to prevent.
------------------------------------------------------------------------------
preservation_score (app/services/research_lab/preservation_score.py; McLean &
Pontiff, Journal of Finance 71(1), 2016, pp. 5-32, doi:10.1111/jofi.12365)
COULD NOT BE COMPUTED for this family, for a structural reason, not a
scheduling one:

  * The score requires the spec's realized DAILY NET RETURN SERIES - max
    drawdown for the Calmar term and the two half-sample Sharpes for the
    stability term. cross_sectional_trial_results persists SUMMARY statistics
    only; no daily series is stored for any family, here or anywhere.
  * run_preservation_score.py obtains the series by REPLAYING each family and
    capturing what the backtest already produces. It excluded this family by
    name, for cost: "its own report records 207.4 minutes of wall clock
    (form 13F parsing). Too expensive for this analysis."
  * That cost is now HIGHER, not lower. backend/data/form13f_raw/ - the
    provider's cache directory (form13f_provider.DEFAULT_CACHE_DIR), gitignored
    - contains 0 files. The 53 SEC quarterly archives (120,182,194 INFOTABLE
    rows) and the ~107 fails-to-deliver archives behind the CUSIP map would
    have to be re-downloaded before any replay could start.
  * No partial computation is available either. Given only the persisted
    Sharpe and DSR, `cred` is known but `RQ` needs Calmar (hence max drawdown,
    hence the series) and `stab` needs the half-sample Sharpes (likewise).
    There is no bound on the score that the persisted summary supports.

WHAT IS KNOWN, and it is only directional: cred = clip(DSR,0,1) = 0.7781 for
the top spec and 0.6275 for bi_conviction_count_h63 - both above every live
registration except cbop (0.817) and si_ratio (0.796). The persisted higher
moments point the other way: the top spec's daily returns carry skewness
-0.560 and kurtosis 9.44, and bi_conviction_count_h63's -0.399 and 10.65 -
negatively skewed and very fat-tailed, the profile the Calmar term exists to
penalise. Neither is a preservation_score and neither is treated as one.

FOR SCALE, from the one run that did compute it
(preservation_score_2026-09-03.json), the four live registrations score:
lazy_prices 0.0852 (stability 0.809), and cbop / si_ratio / noa_neutral all
0.0000 - each because one half of their sample lost money (stability 0). On
the stability-free variant: cbop 0.1073, lazy_prices 0.1054, si_ratio 0.0887,
noa_neutral 0.0421. This family cannot be placed on that ladder.

THIS DOES NOT DRIVE THE DECISION EITHER WAY. Mechanism fidelity is the primary
gate and E.5 fails it on grounds no path statistic could lift or impose. The
check is recorded because it is now a standing criterion and a criterion that
is silently skipped is not a criterion.

E.7  THE DECISION, AND THE HONEST ADMISSION THAT IT IS A CLOSER CALL THAN THE
     THREE DECLINES IN dd288f9
------------------------------------------------------------------------------
DECLINED. No forward-validation registration from this family, including
bi_conviction_count_h63.

Ordered reasons:
  1. E.5(a) is decisive on its own. The paper's body explicitly says its
     result is about manager skill and NOT about whether outsiders can
     piggyback on public holdings data. This family is the piggyback version.
     Its entire literature support is one footnote whose own cross-reference
     turns out to be a persistence figure rather than the public-date evidence
     it claims. A forward-validation slot is a year of calendar time spent on
     a pre-committed hypothesis; the hypothesis here is supported by one
     unverified sentence in a seventeen-year-unpublished manuscript.
  2. E.5(b) and E.5(c) mean that even a forward POSITIVE would not be
     attributable to the paper's mechanism: the short half of the book tests
     something the paper makes no claim about, and the manager population is
     not the one the paper's 13F result is measured on.
  3. E.2 + E.3 disqualify the top-DSR spec specifically and independently:
     it deviates on all three of its own axes and sits on the panel whose
     signal is rank-correlated -0.853 with ownership breadth. Registering the
     grid's maximum would repeat, at a HIGHER DSR, exactly the error the
     noa_neutral registration is now being recommended for removal over.
  4. Capital preservation is the governing objective. Nothing here trades, so
     the direct cost of a wrong registration is zero dollars; the real cost is
     that the registered set is the pipeline from which anything is eventually
     promoted, and admitting a candidate whose source paper disclaims the
     question, whose short leg tests nothing, and whose manager universe is
     not the paper's, lowers that pipeline's standard permanently.

WHAT THIS DECISION IS NOT, and where it is genuinely uncertain:
  * It is NOT a finding that the Best Ideas effect is false. E.4 is real:
     the paper's own measure, at the paper's own aggregation and cadence,
     produced +0.44 Sharpe / DSR 0.63 here, and the faithful axis did not
     collapse. That is a better mechanism-fidelity profile than asset_growth,
     residual_momentum or noa_neutral, and this decline does NOT rest on the
     same ground they do.
  * The evidence is therefore genuinely mixed and is recorded as mixed. A
     reviewer who weighs E.4 above E.5(a) - who takes the view that the
     footnote plus Figure 4's persistence result is adequate literature
     support for the outsider version - would register bi_conviction_count_h63
     and would not be being unreasonable. This decision takes the other view
     because a source that names the exact question and says it is not the
     one being studied is the clearest possible statement of scope, and a
     forward slot is not the place to bet against it.
  * It is NOT a claim that DSR 0.7781 is a bad number. It is the second
     highest this project has seen, behind si_dtc's 0.948 - which was also
     rejected, on the same kind of ground.

WHAT WOULD REVERSE IT, any one of:
  * A PUBLISHED version of the paper, or any published replication of the
     public-filing-date ("outsider") result with its own reported alpha and
     t-statistic. That single change removes reason 1 and most of reason 2's
     weight.
  * A within-manager long/short implementation - long each manager's best
     idea, short that manager's own positions outside their top ten, per
     E.5(b)'s quotation - which is the paper's actual portfolio and a
     structurally different construction from this harness's cross-sectional
     decile spread. That would be a NEW pre-registered family carrying these
     36 trials into its denominator, not a re-read of this grid.
  * A usable point-in-time classification of 13F filers into pure-play hedge
     funds, closing E.5(c). No free source of this is known; it is recorded
     as a paid-data gap alongside the standing securities-borrow item.
  * An explicit, argued human decision to treat the informal 0.5 DSR floor as
     the only gate and drop mechanism fidelity - which would also require
     revisiting si_dtc (0.948), asset_growth (0.670) and residual_momentum
     (0.630), all previously declined on that gate.

Also recorded, because all three push the same way: the residual survivorship
disclosed in this report ("THIS FLATTERS THE RESULTS"), the 0bp financing
assumption, and the fact that the persisted 36 rows are the PRE-C1 CUSIP map's
numbers while the code is now post-C1 - the corrected grid was measured (C1)
but never persisted to cross_sectional_trial_results, so any registration made
today would run code whose backward numbers are not in the database.
