THE MISTAKE IN THE PRIOR COMPARISON, STATED PLAINLY
----------------------------------------------------------------------------------------------------
  Writing a = Item B.6.a, b = Item B.6.b, c = Item B.6.c, D = total
  distributions declared (NOT reported on Form N-PORT), R = fund total return:

    Lou Eq.(1), TNA-inferred : (TNA_t - TNA_{t-1}*(1+R) - MGN_t) / TNA_{t-1}
    B.6 NET                  : a + b - c     <- what PROOF_4 compared against
    B.6 EXTERNAL             : a - c         <- what this run recommends

  B.6 NET adds reinvested distributions back in. Lou's construction excludes
  them BY ASSUMPTION. So PROOF_4 compared a measure that nets distributions OUT
  against a measure that adds them IN, and correctly observed that they differ.

Q2. THE STRUCTURAL IDENTITY, DERIVED AND VALIDATED AGAINST A KNOWN ANSWER
----------------------------------------------------------------------------------------------------
  Net assets move over a quarter as:

    TNA_t = TNA_{t-1} + (P&L net of expenses) - D + a + b - c

  A full-reinvestment, net-of-fees total return R satisfies
  (P&L net of expenses) = TNA_{t-1} * R exactly, under Lou's own stated
  end-of-quarter flow-timing assumption. Substituting:

    EQ1_dollars  ==  (a + b - c) - D  ==  (a - c) - (D - b)              (I)

  In words: LOU'S EQ.(1) EQUALS EXTERNAL NET FLOW MINUS THE DISTRIBUTIONS THAT
  WERE PAID OUT IN CASH RATHER THAN REINVESTED. Two consequences:

    EQ1  <=  (a - c)  <=  (a + b - c)                                   (II)
    D == b  =>  EQ1_dollars == a - c   EXACTLY                          (III)

  (III) is the resolution: under Lou's literal assumption, his Eq.(1) IS
  B.6 EXTERNAL. The disagreement PROOF_4 found is the failure of that
  assumption in the real world, and its size is the cash-distribution amount.

  VALIDATED AGAINST SYNTHETIC DATA WITH A KNOWN TRUE ANSWER, per CLAUDE.md's
  rule that a published formula is never trusted before it reproduces a
  hand-derivable case. `simulate_fund_quarter()` builds fund-quarters from
  primitives where the true external flow is known by construction;
  `identity_residual()` is zero to within 1e-12 of TNA across every case
  tested, including a case parameterised to the real Vanguard fund-quarter
  below. A worked known-answer case, pinned in the test file:
    TNA_prev 10,000, return +7.5%, subscriptions 1,000, redemptions 1,000,
    distributions 200, reinvestment rate 25%
      -> true external flow  =    0 (by construction)
      -> B.6 EXTERNAL (a-c)  =    0   CORRECT
      -> B.6 NET (a+b-c)     =  +50   reads a zero-flow quarter as an INFLOW
      -> Lou Eq.(1)          = -150   reads a zero-flow quarter as an OUTFLOW
    That is PROOF_4's sign disagreement, reproduced from primitives, with the
    true answer known: BOTH of the two definitions the prior run compared are
    wrong about this quarter, and the third one is exactly right.

MECHANISM-FIDELITY DEVIATION LOG (per CLAUDE.md)
----------------------------------------------------------------------------------------------------
  DEVIATION: use Form N-PORT Item B.6.a - Item B.6.c in place of Lou (2012)
  Section 2.2 Eq.(1) as the flow input.

  REASONING: Lou (2012) Section 2.2 states verbatim that he assumes "investors
  reinvest their dividends and capital appreciation distributions in the same
  fund". Under that assumption Eq.(1) is algebraically identical to
  B.6.a - B.6.c (identity (III), validated against synthetic data with a known
  answer). Eq.(1) is therefore an ESTIMATOR of B.6.a - B.6.c, adopted by Lou
  because CRSP/CDA reported no direct flow figure. Form N-PORT reports the
  estimand directly. The substitution changes the ESTIMATOR, not the ESTIMAND,
  and removes two of Lou's own named approximation errors (the reinvestment
  assumption entirely; the flow-timing assumption partly, since B.6 is reported
  monthly). Measured effect on 49,705 real fund-quarters: Spearman 0.9726 with
  Eq.(1), 94.01% sign agreement, 95.25%/92.74% retention of the top/bottom flow
  deciles.

  RESIDUAL FIDELITY GAP NOT CLOSED: Lou's MGN merger adjustment cannot be
  reproduced from N-PORT under either definition (see Q5(2)).
