ถ้าอ่านแค่ 5 บรรทัด

  1. คำถามใหญ่ที่สุดของรอบนี้ไม่ใช่ "pattern ไหนดี" แต่คือ "สถาปัตยกรรมการค้นหาเองอาจผิดจุด" — สามวรรณกรรมที่แยกกันคนละสาย (empirical-Bayes shrinkage, virtue-of-complexity, และเรื่องเล่าที่ยืนยันได้ของ Renaissance) ชี้ไปทางเดียวกัน: ระบบที่ gate สัญญาณทีละตัวก่อนรวมอาจ "หาสิ่งที่มันตามหาไม่เจอโดยโครงสร้าง" — ดูหัวข้อ 5
  2. เจอแหล่งข้อมูลฟรีที่ไม่เคยใช้ 4 แหล่งใหญ่ — CBOE (VIX/SKEW/implied-correlation ย้อนหลังถึง 1990), SEC EDGAR (fundamentals แบบ point-in-time + วันที่ earnings/buyback/13D ย้อนหลังถึง 2001-2004), Open Source Asset Pricing (factor ready-made 200+ ตัว), Binance funding-rate API — ดูหัวข้อ 2
  3. ผู้สมัครที่น่าเชื่อถือที่สุด 3 ตัว (mechanism ชัด + ข้อมูลฟรี + ยังไม่ arbitraged หมด): cash-based operating profitability, correlation risk premium, PEAD ผ่าน earnings-announcement-return proxy — ดูหัวข้อ 3
  4. โครงการมีเครื่องมือแก้บั๊กสถิติที่ยังไม่ได้ implement — effective-N ผ่าน clustering (แทนการประกาศ N ตายตัว), empirical-Bayes shrinkage บน ~450 trial ที่มีอยู่แล้ว, HRP แทน raw covariance ใน optimizer — สามอย่างนี้อาจให้คุณค่ามากกว่า pattern ใหม่ตัวไหนก็ตาม — ดูหัวข้อ 5
  5. checklist กรองก่อนทดสอบจริง จากงานวิจัยเรื่อง replication crisis โดยเฉพาะ — ใช้ตัดไอเดียที่รู้อยู่แล้วว่าอ่อนก่อนเสียเวลา compute — ดูหัวข้อ 6

02ผู้สมัคร pattern ใหม่ — จัดลำดับความน่าเชื่อถือ

คลิกเปิดแต่ละอันเพื่อดูรายละเอียด — mechanism, แหล่งอ้างอิงจริง, ความเป็นไปได้ด้านข้อมูล, และการประเมินความน่าเชื่อถืออย่างตรงไปตรงมา (รวมกรณีที่วรรณกรรมบอกว่าอ่อนแล้ว)

Tier S — ทดสอบก่อน Tier A — ทดสอบ แต่ discount หนัก Tier B — เป็น negative control Tier C — ข้าม/บันทึกว่า researched-and-declined
SCash-based operating profitabilityBall, Gerakos, Linnainmaa & Nikolaev 2016, JFE

Mechanism

แยกกำไรจากดำเนินงานเฉพาะส่วนที่เป็นเงินสดจริงออกจาก accrual — ส่วนเงินสดคงทนกว่าและ manipulate ยากกว่า เป็นตัวทำนายที่ดีกว่าทั้ง accruals เดี่ยวๆ และ profitability แบบรวม accrual

ข้อมูล

ต้องสร้าง pipeline EDGAR XBRL ใหม่ (revenue, COGS, assets — มี filing date จริง) — แต่ครอบคลุมทั้ง accruals anomaly (Sloan 1996, พิสูจน์แล้วว่าถูก arbitrage จนหายเกือบหมด — Green/Hand/Soliman 2011) และ gross profitability (Novy-Marx) ในการดึงข้อมูลครั้งเดียว

ความน่าเชื่อถือ

ผู้เขียนอ้างว่าไม่มี post-publication decay แต่ sample จบ ~2013-2015 — ต้องทดสอบเป็นคำถามเปิด ไม่ใช่รับมาเลย จุดแข็งจริง: ยุบ 3 ตัวสมัครในตระกูล fundamentals ให้เหลือ 1 สัญญาณ ซึ่งช่วยลด DSR denominator

SNet operating assets (NOA)Hirshleifer, Hou, Teoh & Zhang 2004, JAE

Mechanism

ช่องว่างสะสมระหว่างกำไรทางบัญชีกับกำไรเงินสด สะสมในงบดุล — บริษัทที่ balance sheet "บวมพอง" จากการโป่ง accrual สะสมมานาน มักจะ underperform

ข้อมูล

EDGAR XBRL เดียวกับด้านบน แต่ต้อง tag มากกว่าและ normalize ยากกว่า

ความน่าเชื่อถือ

รอดจากการทดสอบ replication ของ Hou-Xue-Zhang เอง (−0.4%/เดือน แบบ value-weighted, ไม่ถูกอธิบายหมดโดย q-factor) — เป็นหนึ่งในไม่กี่ตัวจากตระกูล accounting anomaly ที่รอด นี่คือสิ่งที่ต่างจาก Sloan accruals ตรงๆ

SPEAD ผ่าน Earnings Announcement Return (EAR) proxyBrandt, Kishore, Santa-Clara & Venkatachalam

Mechanism

ใช้ผลตอบแทนช่วงประกาศงบเอง (ไม่ใช่ analyst-surprise) เป็นตัวทำนาย drift ต่อเนื่อง — งานวิจัยพบว่า EAR ทำนายได้ ดีกว่า SUE แบบดั้งเดิม (7.55%/ปี ปะทะ 6.25%/ปี) และไม่มี reversal หลัง 3 ไตรมาส

ข้อมูล

ต้องการแค่วันที่ประกาศงบ + ราคา OHLC — ไม่ต้องมี consensus estimate เลย ปิดช่องว่างที่เคยคิดว่าต้องใช้ paid data feed EDGAR 8-K Item 2.02 ให้วันที่แม่นระดับวันตั้งแต่ 2004

ความน่าเชื่อถือ

PEAD คือ anomaly ที่ replicate ดีที่สุดตัวหนึ่งในวรรณกรรมทั้งหมด (Hou-Xue-Zhang ยืนยัน) และมี event นับแสนตัว (~150,000+) — เป็นตระกูล event-driven เดียวที่มี sample ใหญ่พอจะผ่าน DSR gauntlet ได้จริง ตัวอื่นในกลุ่ม event-driven ทั้งหมด underpowered โดยโครงสร้าง (ดู Tier C)

SCorrelation risk premiumDriessen, Maenhout & Vilkov; CBOE COR1M/COR3M

Mechanism

implied correlation (จาก index vol เทียบ constituent vol) ลบ realized correlation = ราคาที่นักลงทุนจ่ายเพื่อป้องกันการสูญเสีย diversification ตอนตลาดล่ม ยิ่งพรีเมียมสูง ยิ่งบ่งชี้ risk aversion สูง

ข้อมูล

ฟรีสมบูรณ์ ยืนยันสดแล้ว — CBOE COR1M/COR3M ย้อนหลังถึง 2006-01-03 ครบ 5,195 แถวถึงวันนี้ ไม่ต้องมี vendor เลย

ความน่าเชื่อถือ

อัตราส่วนข้อมูลฟรี-ต่อ-ความใหม่ดีที่สุดในกลุ่ม options — แต่ต้องทำ orthogonalize กับสัญญาณ vol-regime timing ที่ reject ไปแล้ว เพราะ implied correlation ผูกกับ VIX โดยธรรมชาติ ถ้าไม่ทำขั้นนี้ ผลบวกที่ได้อาจเป็นแค่ signal เดิมที่ reject ไปแล้วในชื่อใหม่

ALiquidity shocks (ΔILLIQ)Bali, Peng, Shen & Tang 2014, RFS

Mechanism

ตลาด underreact ต่อ "shock" ของสภาพคล่อง (การเปลี่ยนแปลงฉับพลันของ Amihud illiquidity เทียบ baseline) — shock ทำนาย return ต่อเนื่องได้ถึง 6 เดือน จาก investor inattention

ข้อมูล

OHLCV เท่านั้น ไม่ต้องมี share-count ที่แม่นยำ (ต่างจาก turnover-based signals ที่มีปัญหาข้อมูล)

ความน่าเชื่อถือ

โปรไฟล์ cost ดีที่สุดในกลุ่ม liquidity/microstructure — holding period 1-6 เดือนทำให้ turnover ต่ำพอจะรอด cost ตาม Novy-Marx/Velikov's 50% turnover rule ต่างจาก 420 patterns ที่ตายเพราะ turnover สูงเกินไป

AOvernight/intraday return decomposition ("tug of war")Lou, Polk & Skouras 2019, JFE

Mechanism

overnight return (close→open) กับ intraday return (open→close) ของหุ้นตัวเดียวกัน มี continuation ในตัวเอง แต่ reversal ข้ามกัน — คนละกลุ่มนักลงทุนเทรดคนละช่วงเวลา

ข้อมูล

ไม่ต้องข้อมูลใหม่เลย (มี Open ใน OHLC อยู่แล้ว) แต่ต้อง audit คุณภาพ Open price ก่อน — yfinance-class ไม่ adjust Open ให้สอดคล้องกับ split/dividend เท่า Close เสมอไป ถ้าไม่เช็คก่อน สัญญาณที่ได้อาจเป็น artifact ล้วนๆ

ความน่าเชื่อถือ

เป็นปรากฏการณ์ทางสถิติที่ replicate ดีมาก (แข็งแรงขึ้นในครึ่งหลังของ 30 ปีที่ทดสอบด้วยซ้ำ) แต่ Alpha Architect review พบว่า trading cost กิน edge จนหมดในเวอร์ชันไร้เดียงสา — เป็น "ปรากฏการณ์จริง, edge สุทธิยังไม่พิสูจน์"

ASame-calendar-month seasonality (cross-sectional)Heston & Sadka 2008; Keloharju, Linnainmaa & Nyberg 2016, JF

Mechanism

หุ้นที่เคย return ดีในเดือนหนึ่ง (เทียบเพื่อน) มักจะ return ดีในเดือนเดียวกันซ้ำทุกปี — ต่างจาก day-of-week (ที่ reject ไปแล้ว) เพราะเป็น cross-sectional stock-specific ไม่ใช่ market-wide effect

ข้อมูล

ใช้ point-in-time S&P membership ที่มีอยู่แล้ว — ส่วนที่ยากที่สุดสร้างไว้แล้ว

ความน่าเชื่อถือ

replicate ดีในหลายตลาด (แคนาดา ญี่ปุ่น ยุโรป 12 ประเทศ) แต่ผู้เขียนเองเตือนว่ามัน "พันกันกับ anomaly อื่นผ่าน exposure ร่วม" — สิ่งที่เจออาจเป็น exposure เดิมที่ reject ไปแล้วในคราบใหม่ ต้องเช็คก่อน

APerpetual-futures funding-rate carry (crypto)Schmeling, Schrimpf & Todorov 2023, BIS WP

Mechanism

ความต้องการ leverage-long ใน perpetual futures ดัน funding rate ให้ long จ่าย short — เป็น structural carry ที่แท้จริงของ crypto ไม่เหมือน carry อื่นที่ arbitrage หมดแล้ว

ข้อมูล

ฟรี ไม่ต้อง key — Binance public endpoint `fapi/v1/fundingRate` แต่เป็น provider ใหม่ (ไม่ใช่ yfinance) ต้อง integrate เพิ่ม และผูกกับ exchange เดียว (ควรมี venue ที่สองเพื่อความทนทาน)

ความน่าเชื่อถือ

เป็น crypto anomaly ที่มี mechanism ชัดเจนที่สุด แต่เป็นการเทรดที่แออัดที่สุดด้วย — มีรายงาน (ยังไม่ verify ตัวเลขแน่ชัด) ว่า Sharpe ลดจาก ~6 เหลือติดลบในปี 2025 เป็น time-series signal บนเหรียญไม่กี่ตัว ไม่ใช่ cross-sectional — breadth ต่ำ กระทบ DSR

AOil futures curvature → non-oil equitiesChiang & Hughen 2017, JBF

Mechanism

ความโค้งของ oil futures curve ทำนาย supply-shock ที่กระทบภาคที่ไม่ใช่พลังงานเป็นต้นทุน (บริษัทพลังงานมักจะ hedge ตัวเองอยู่แล้ว) — ทิศทางตรงข้ามกับสัญชาตญาณ ("oil นำ energy stocks") ที่งานวิจัยปฏิเสธไปแล้ว

ข้อมูล

ใช้ commodity futures curve ที่มีอยู่แล้วในโปรเจกต์ — feasibility ดีที่สุดในกลุ่ม lead-lag

ความน่าเชื่อถือ

เป็น monthly signal (~240 observation ใน 20 ปี) — ต้องเช็คว่าไม่ collinear กับ Commodities family ที่ reject ไปแล้ว (ซึ่งพบว่าเป็น precious-metals beta แฝง) ก่อนนับเป็น independent bet

ACross-asset FX shock → equity (FOREXS, coarse proxy)Bae, Da & Zurita 2024, Management Science

Mechanism

firm ที่ไม่ hedge FX exposure ครบ + นักลงทุนไม่สนใจ asset class อื่น (limited attention ข้าม asset class) = FX shock ทำนาย cash flow และ return หุ้นในอนาคต — long-short earned 6.74%/ปี

ข้อมูล

เวอร์ชันเต็มต้องมี Compustat geographic-segment revenue (ไม่มี) — เวอร์ชัน coarse (FX-vol/carry-unwind state) สร้างได้จาก major FX data ที่มีอยู่

ความน่าเชื่อถือ

ตีพิมพ์ปี 2024 — ยังไม่ผ่านช่วง post-publication decay เป็นข้อได้เปรียบจริง friction ข้าม asset-class เป็น institutional ไม่ใช่ technological จึง arbitrage ยากกว่า lead-lag ภายใน asset class เดียวกัน แต่ต้องระวังไม่ให้ทับกับ vol-regime signal ที่ reject ไปแล้ว (Menkhoff et al.: FX vol เป็น priced risk factor)

BTurn-of-month / pre-holiday effectsLakonishok & Smidt 1988; Ariel 1990 — ทดสอบเป็น negative control

ทำไมถึงเป็น Tier B

วรรณกรรมล่าสุด (2024-2025) ยืนยันตรงๆ ว่า turn-of-month effect หายไปหมดหลังปี 2001 (decimalization) และ pre-holiday effect เหลือแค่ในหุ้นเล็กเท่านั้น — นี่คือจุดที่มีประโยชน์ที่สุดในฐานะ negative control: ถ้า pipeline รายงานผลบวกจาก pattern ที่วรรณกรรมบอกว่าตายไปแล้ว นั่นคือสัญญาณว่า DSR machinery มีบั๊ก ไม่ใช่ว่าเจอ edge จริง

BClassic lead-lag: large-cap → small-capLo & MacKinlay 1990; Hong 2007 — ทดสอบเป็น null calibrator

ทำไมถึงเป็น Tier B

งานวิจัยปี 2015 (Tse) ทดสอบซ้ำถึงปี 2013 พบว่าเหลืออุตสาหกรรมที่ significant แค่ 1-7 จาก 48 อุตสาหกรรม และ Chordia-Subrahmanyam-Tong พบว่า anomaly profit รายวันลดลงครึ่งหนึ่งหลัง decimalization — สร้างเป็นตัวสอบเทียบ ไม่ใช่ candidate: ถ้า pipeline หา Sharpe ที่ดีจาก pattern ยุค 1990 นี้บน sample สมัยใหม่ได้ ให้สงสัย DSR machinery ก่อน ไม่ใช่ดีใจว่าเจอ edge

CMAX effect / lottery demandBali, Cakici & Whitelaw 2011 — ข้าม

Hou-Xue-Zhang ระบุชื่อตรงๆ ว่าเป็นหนึ่งใน friction variable ที่ insignificant เมื่อใช้ NYSE breakpoints + value-weight — universe ของโปรเจกต์นี้ (S&P 500/600, ไม่มี microcap) คือจุดที่มันอ่อนที่สุดพอดี และพันกับ IVOL anomaly ที่ reject ไปแล้ว

CBetting-against-beta ระดับหุ้น (ไม่ใช่ crypto)Frazzini & Pedersen 2014 — ข้าม

แม้จะฟรี (ราคาอย่างเดียว, ไม่ต้องข้อมูลใหม่) แต่งานวิจัยล่าสุด (Bali et al. 2017) พบว่า beta anomaly ระดับหุ้นถูกอธิบายหมดโดย lottery demand — คือ IVOL anomaly ในชื่อใหม่ ซึ่งโปรเจกต์นี้ reject ไปแล้ว ถ้าจะทดสอบ ต้อง pre-declare ว่าไม่นับเป็น independent bet

CSpin-offs, stock splits, dividend initiation/omission เป็น discrete eventหลายแหล่ง — ข้าม เพราะ underpowered

ทั้งหมดมี effect จริงในวรรณกรรมยุคแรก แต่ (ก) เหตุการณ์น้อยเกินไป (~20-40 spinoff/ปี, ~500 event สะสมทั้งหมด) ทำให้ underpowered โดยโครงสร้างไม่ใช่ reject จาก evidence และ (ข) หลายตัว (splits, buyback announcement) พบว่า effect หายไปเกือบหมดใน sample หลังปี 2000 — 6 จาก 7 ผู้สมัครในกลุ่ม event-driven ตกกลุ่มนี้ มีแค่ PEAD (ด้านบน) ที่มี event เยอะพอ

03อัปเกรดวิธีการค้นหาเอง — อาจสำคัญกว่า pattern ไหนก็ตาม

ทีมวิจัยด้าน methodology (แยกจากทีมหา pattern) กลับมาพร้อมข้อค้นพบเชิงกลยุทธ์ที่ใหญ่กว่าที่คาด

คำถามใหญ่ที่สุด: วรรณกรรมสามสายที่เป็นอิสระต่อกัน — empirical-Bayes shrinkage (Chen & Dim, "High-Throughput Asset Pricing"), virtue-of-complexity (Kelly, Malamud & Zhou, JF 2024), และเรื่องราวที่ยืนยันได้ของ Renaissance ("โมเดลเดียวรวมทุก asset class" ไม่ใช่กลยุทธ์แยกที่ผ่าน gate ทีละตัว) — ชี้ไปทางเดียวกัน: ระบบที่ gate สัญญาณแต่ละตัวให้ผ่าน significance ก่อนรวม อาจหาสิ่งที่มันตามหาไม่เจอได้เลยโดยโครงสร้าง วินัยทางสถิติของโปรเจกต์นี้ยอดเยี่ยมกว่างานตีพิมพ์ส่วนใหญ่แล้ว — ความเสี่ยงคือมันถูกใช้ผิดระดับความละเอียด (granularity) ไม่ใช่ผิดหลักการ
เลขคณิตที่ตรงไปตรงมา (Grinold's Fundamental Law): IR = TC · IC · √BR — ตอนนี้โปรเจกต์มี BR (breadth, จำนวนเดิมพันอิสระ) ≈ 1 ตัว (crypto BAB) จะได้ portfolio IR = 1.0 ที่ IC สมจริง 0.05 และ TC 0.6 ต้องมี BR ~1,100 เดิมพันอิสระต่อปี — สรุปตรงๆ: อุปสรรคหลักคือความกว้าง (breadth) ไม่ใช่คณิตศาสตร์การแก้ไข ความกว้างมาจากสินทรัพย์เยอะขึ้น + horizon สั้นลง ไม่ใช่จากการแก้สถิติให้ดีขึ้น

SEffective-N ผ่าน unsupervised clusteringLópez de Prado & Lewis 2019, Quantitative Finance

แทนที่จะประกาศ N ตายตัว (เช่น 212 pattern) ให้ cluster equity curve ของทุก trial แล้วใช้จำนวน cluster เป็น N ที่แท้จริง — 212 pattern variant ที่สหสัมพันธ์กันสูงไม่ใช่ 212 trial อิสระ วิธีนี้แปลง TODO ที่ค้างอยู่ใน cross_sectional_buyback.py:470 ให้เป็นวิธีที่อ้างอิงได้จริง ใช้แค่ correlation matrix ของ equity curve ที่มีอยู่แล้ว

SEmpirical-Bayes shrinkage บนผลที่มีอยู่แล้วทั้งหมดChen & Dim, "High-Throughput Asset Pricing," arXiv 2311.10685

วิเคราะห์ ~450 trial ที่เก็บไว้แล้วซ้ำ — ประมาณค่าการกระจายตัวของ "true expected return" จากทั้ง population แล้ว shrink ทุก t-stat เข้าหาศูนย์ตามนั้น แทนที่จะเป็น pass/fail แบบ binary จะได้ posterior ที่จัดอันดับได้ — เข้ากับ vision "many weak signals" ของโปรเจกต์มากกว่า gate แบบ binary ไม่ต้องรัน backtest ใหม่เลย เป็นการวิเคราะห์ข้อมูลที่มีอยู่แล้ว

SHRP หรือ covariance shrinkage แทน raw sample covarianceLópez de Prado 2016 (HRP); Ledoit-Wolf shrinkage

optimizer ปัจจุบันรัน SLSQP max-Sharpe บน raw cov() — เป็นค่าประมาณที่ error ขยายตัวมากที่สุดในวรรณกรรม literature เรื่อง forecast combination พบซ้ำๆ ว่า equal-weight ชนะ estimated-optimal weight เพราะ estimation error ท่วมประโยชน์ทางทฤษฎี — ข้อสังเกตที่มีอยู่แล้วว่า cap 0.4 ที่ n=3 ทำให้ optimizer ไม่ตัดอะไรเลย เป็นอาการของปัญหานี้ ไม่ใช่ความบังเอิญ

APower / Type II analysis ต่อ familyHarvey & Liu 2020, JF

ตอนนี้ "reject" กับ "underpowered" รายงานเหมือนกันหมด — ทั้งที่ความหมายต่างกันมาก การคำนวณ power ต่อ family (ต้องมี Sharpe เท่าไหร่ถึงจะ detect ได้ที่ 80% power ด้วยจำนวน formation ที่มี) ราคาถูกและเปลี่ยนวิธีอ่านผลลบที่มีอยู่แล้วทั้งหมด

AOnline FDR (alpha-investing) ข้าม research pushFoster & Stine; Ramdas et al. (SAFFRON)

จัดสรร "alpha-wealth" ล่วงหน้าข้าม research push ที่ต่อเนื่องไม่มีที่สิ้นสุด แทนที่จะขยาย DSR denominator ย้อนหลัง — ตรงกับวิธีที่โปรเจกต์นี้ทำงานจริง (push ต่อ push, trial count โตขึ้นเรื่อยๆ) เป็นคำตอบที่เป็นระบบสำหรับปัญหา "รัน 8 family ในคืนเดียว" ที่ตอนนี้แก้แบบ ad-hoc

ดูรายละเอียดฉบับเต็ม 10 ข้อ (รวม Minimum Backtest Length, Romano-Wolf stepwise test, และเหตุผลที่ meta-labeling/genetic programming ยังไม่เหมาะกับสเตจนี้) ในบันทึกงานวิจัยแยกต่างหาก

04Checklist กรองก่อนทดสอบจริง

จากทีมวิจัย adversarial-skeptic โดยเฉพาะ — สร้างจากวรรณกรรม replication-crisis เพื่อคัดไอเดียที่รู้อยู่แล้วว่าอ่อน ก่อนเสียเวลา compute ไม่ใช่หลัง

ตั้ง prior ให้ถูกก่อน: สำหรับ pattern ที่ mine เองจากสถิติล้วนๆ ไม่มี mechanism ระบุชื่อ อ้างอิงจาก Chordia-Goyal-Saretto (ทดสอบ 2 ล้านกลยุทธ์ พบ 45.3% false-rejection rate ถ้าไม่แก้) และ Hou-Xue-Zhang (65% ของ anomaly ที่ตีพิมพ์แล้วยังตกเมื่อทดสอบ value-weighted) — โอกาสที่จะเจอ edge จริงที่รอด cost คือระดับ single-digit percent ผู้สมัครต้อง "ชนะ" prior นี้ก่อนถึงจะคุ้มค่า compute

A. Hard kill — หยุดทันที ไม่ต้อง backtest

  • เคยถูกทดสอบและ fail ใน replication library ขนาดใหญ่แล้ว (HXZ 452 ตัว, Open Source Asset Pricing 319 ตัว, JKP 153 factor/93 ประเทศ) — เช็คก่อน มีโค้ด+ข้อมูลให้ใช้ฟรี
  • economics ของสัญญาณคือ microcap/illiquidity ล้วนๆ — HXZ พบว่า trading-frictions category fail 96%
  • สร้างไม่ได้แบบ value-weighted + NYSE breakpoint
  • turnover ที่ต้องการเกิน ~50%/เดือน (Novy-Marx/Velikov: เกินนี้แล้วแทบไม่รอด cost)
  • อธิบาย mechanism เป็นประโยคเดียวไม่ได้ — "มันปรากฏในข้อมูล" ไม่ใช่ mechanism
  • เอียงไปทาง distress/small-cap/bankruptcy-adjacent ที่โดนช่องว่าง delisted-securities coverage ที่เปิดอยู่กระทบโดยตรง

B. ยกระดับ hurdle (แต่ละข้อยกบาร์สูงขึ้น)

  • ค้นพบก่อนปี 2000 หรือหลัง? — ก่อน 2000 ใช้ McLean-Pontiff haircut 58% เต็มที่ ก่อนแม้แต่จะ backtest
  • mine จาก CRSP/Compustat panel เดียวกับทุกคน? → บาร์ขั้นต่ำ t≥3.0 (Harvey-Liu-Zhu) ยกเป็น t≥3.4-3.8 ถ้ามาจาก automated sweep กว้างๆ (Chordia-Goyal-Saretto)
  • นับ forking path ไม่ใช่แค่จำนวน pattern — ทุก degree of freedom ในการวิเคราะห์ (universe, rebalance freq, cost model, lag convention ฯลฯ) ต้องนับรวม ไม่ใช่แค่ "เราทดสอบ 212 นิยาม"
  • เช็ค Minimum Backtest Length ก่อนรัน — sample สั้นเกินไปสำหรับจำนวน trial ที่ตั้งใจจะทำหรือเปล่า
  • สหสัมพันธ์กับ theme ที่มีอยู่แล้วในพอร์ตหรือไม่ (|ρ|>0.7)? → ต้องทดสอบเป็น alpha ส่วนเพิ่ม ไม่ใช่แยกเดี่ยว — นี่คือขั้นที่ Commodities family (precious-metals beta แฝง) พลาดไปตอนแรก

C. Mechanism gate — เขียนก่อนเห็นผล ประทับเวลาไว้

  • structural/institutional (index rebalance, มาตรการกำกับ) → ทนทานที่สุด
  • behavioral bias ที่มีอ้างอิง → ทนทานปานกลาง แต่โดน arbitrage ได้เมื่อรู้กันทั่วไป
  • risk compensation → ทนทานแต่ไม่ใช่เงินฟรี ต้องเช็คว่ายอมรับความเสี่ยงนั้นได้จริง
  • สถิติล้วนๆ ("config นี้ Sharpe ดีที่สุด") → สมมติว่าเป็น noise ไว้ก่อน
  • ระบุคู่ตรงข้ามได้ไหม (ใครเสียเปรียบ และอะไรบังคับให้เขาทำแบบนั้นต่อไป)?

D. เช็คราคาถูกก่อน backtest เต็ม (นาทีเดียวต่อข้อ)

  • ตัด size quintile เล็กสุดออก — ถ้า effect หายไปครึ่งหนึ่ง แปลว่าเป็น microcap contamination
  • ทดสอบย้อนหลังก่อนช่วงที่ค้นพบ (ถ้ามีข้อมูล) — สัญญาณของ snooped anomaly: return ลด, volatility และ cross-correlation กับ anomaly อื่นเพิ่มพร้อมกัน
  • placebo test — รันสัญญาณที่ไม่มีความหมายทางเศรษฐศาสตร์ผ่าน harness เดียวกัน ถ้าได้ t-stat ใกล้เคียงกัน แปลว่า harness เองสร้าง significance ปลอมได้

E. "ดูดีเกินไป" — ต้องยกระดับการตรวจสอบ ไม่ใช่ fast-track

  • McLean-Pontiff พบว่า post-publication decay สูงสุดที่ผลตอบแทน in-sample สูงสุด — ผลที่โดดเด่นคือหลักฐานของ winner's-curse ที่มากกว่า ไม่ใช่ edge ที่ดีกว่า (ตรงกับที่โปรเจกต์นี้ทำกับ Commodities/Buyback อยู่แล้ว — ใช้หลักการเดียวกันต่อไป)
